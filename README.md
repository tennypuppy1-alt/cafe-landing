# cafe-landing

가상의 동네 카페 "모닝브루"를 소개하는 간단한 랜딩 페이지입니다. 순수 HTML과 CSS만으로 만들었고, 별도 빌드 과정이 없습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 스타일 (카페 느낌의 브라운 톤, 모바일 대응) |

## 실행 방법

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 참고

페이지에 나오는 카페 이름, 메뉴, 가격, 주소는 모두 예시입니다.
